# Prints das páginas de Help

Coloque aqui as capturas de tela de cada passo dos tutoriais. O nome do arquivo deve
bater exatamente com o `image` definido em `locales/pt-BR/help.json` (e `es-ES`).
Enquanto o arquivo não existir, a página mostra um placeholder com o nome esperado.
